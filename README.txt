FAMILY RADIUS HOSTING PACKAGE

Open index.html to preview the collection locally.

FASTEST PUBLISHING OPTION
1. Sign in to Netlify.
2. Open Netlify Drop.
3. Drag the entire family-reports-site folder into the upload area.
4. Netlify will provide a shareable web address.

CLOUDFLARE PAGES
1. Open Workers & Pages in Cloudflare.
2. Create an application and choose Pages / Direct Upload.
3. Upload this folder or its ZIP file.
4. Cloudflare will provide a pages.dev address.

PRIVACY
The included headers ask search engines not to index the site. This is not password protection: anyone with the URL can view the reports.
